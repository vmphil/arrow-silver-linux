Arrow Silver Linux for PineTab2

A lightweight Debian + XFCE tablet OS that just works in landscape.

Arrow Silver is a Debian forky (testing) based ARM64 distro built for the PINE64 PineTab2. It boots straight from a microSD card, starts in landscape with the touchscreen already matched to the screen, and gets you to a clean, fast XFCE desktop with Wi-Fi working out of the box. When you're ready, a built-in installer copies it to the tablet's internal storage.

  • Reliable landscape orientation and touch, from the boot console to the desktop
  • Working BES2600 Wi-Fi with bundled firmware
  • XFCE 4.20 with a tablet-friendly dock, Spectral Browser and Firefox ESR
  • GNOME Software with Flathub preset for easy app installs
  • Boot from SD, with an optional one-step install to eMMC (SPI flash is never touched)

Overview

Raw disk image for the PINE64 PineTab2 (Rockchip RK3566). Boots from microSD via U-Boot, with an optional installer to internal eMMC. Built from the Arrow Silver ARM64 base system (the same system as the UEFI ISO).

  • Base: Debian forky (testing), ARM64
  • Kernel: Debian linux-image-arm64 7.2.11 (7.2.11-1)
  • Image release: 2026-10-23

Spectral Browser

Spectral Browser is a small, privacy-focused tabbed web browser written in Go on GTK 3 and WebKit2GTK 4.1. It comes preinstalled in Arrow Silver for PineTab2.

  • HTTPS-only browsing: http:// addresses are upgraded to HTTPS. If a site only works over HTTP, you can load it over HTTP for that session. Local addresses are left alone.
  • Tracker and ad blocking: blocks about 95,000 known tracker and ad hosts from EasyPrivacy and EasyList.
  • Cookies are off unless you allow them: a 🛡/🍪 button switches cookies on or off for each site. Third-party cookies are always blocked, and Google's domains count as one site, with an Allow cookies for Google bar so Google sign-in works.
  • Cookies cleared on close: all cookies are deleted when the browser closes (on by default). The data unallowed sites stored in the browser is deleted too.
  • Ghost Panel (F8): a live view of active connections, outgoing requests (blocked ones in red, third-party in orange) and incoming responses. It only monitors while it is open. Closing it stops monitoring and erases what it collected, lists are capped, and nothing is written to disk.
  • Hardened by default: web pages run in a bubblewrap sandbox. DNS prefetch and WebRTC are off, and pages can't open pop-ups or read the clipboard on their own. Camera, mic, location and notification requests are denied unless you allow them.
  • Private windows and Clear browsing data.
  • Tabs: drag to reorder, open links in background tabs, and use full keyboard shortcuts (Ctrl+T/W/Tab/1–9).
  • Downloads: a save dialog that never overwrites files without asking, a progress bar, and a Downloads window. Pages can be saved as HTML or .mhtml archives, and the right-click menu has save and open-in-new-tab options.
  • Favorites bar, homepage, dark mode, and DuckDuckGo search from the address bar.
  • Light on resources: a smaller page cache (1.3.2) and a Ghost Panel that uses nothing while it is closed.

Install guide

  1. Flash to microSD (erases the card; replace /dev/mmcblkX):
    xz -dc arrow-silver-pinetab2-2026-10-23.img.xz | sudo dd of=/dev/mmcblkX bs=64M status=progress conv=fsync && sync
  2. Boot from SD. The root partition grows to fill the card on first boot.
  3. Optional eMMC install: System menu → “Install Arrow Silver to internal storage”, or sudo arrow-silver-install-emmc --dry-run to preview. It erases the whole eMMC (type ERASE to confirm), writes GPT with U-Boot at sector 64, a 512 MiB /boot (AS-boot-emmc) and / (AS-root-emmc) with fresh UUIDs, and asks you to create your own user.

Disk layout: 6 GiB GPT image — 16 MiB reserved for GPT/U-Boot, 512 MiB ext4 /boot, ext4 /.

Known limitations

  • No Bluetooth (no BES2600 Bluetooth driver)
  • The BES2600 Wi-Fi driver is occasionally unstable
  • Cameras don't work
  • Deep suspend isn't used (s2idle only)
  • Yakuake isn't available
  • The original PineTab (A64) isn't supported
